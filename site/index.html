SMALL POSTGRES CLIENT WITH A MAP FOR MACOS

rgrip is a native PostgreSQL client for macOS, written in Rust. Query, browse and edit your tables, and see PostGIS data on a map right next to the rows it came from.

The map shares the grid's selection

Open a table with a geometry column and put the map next to the rows. Select rows and their features light up; click a feature and its row is selected. One selection, two views.

What the map does
Split viewGrid and map side by side, resizable
Zoom to selectedFit the map to the rows you picked
Filter by areaDraw a box, get a WHERE clause
Reprojects4326 · 3857 · UTM
BasemapsDark, light, streets, satellite

Files go straight into tables

Right-click a schema, pick a file, check the preview and the column types, and import. rgrip creates the table, adds a key so the rows can be edited, and loads it all in one transaction.

What import reads
CSV / TSVDelimiter found for you; lon/lat become a point
GeoJSONProperties become columns
ShapefileSRID read from the .prj
New or existingCreate a table or append to one
All or nothingOne COPY, rolled back on any error

Get rgrip

Download the zip, unzip it and open rgrip.app. It isn't notarized yet, so the first time, right-click it and choose Open. Updates install from inside the app.

Download for macOS

Build from source

Needs Rust 1.88 or newer.

git clone https://github.com/yoouTaro/rgrip
cd rgrip && cargo run -p rgrip
