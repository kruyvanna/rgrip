The PostgreSQL client that speaks geometry.

A minimal, DataGrip-style PostgreSQL client built in Rust with egui. Query, edit and follow relations — then see your PostGIS data on a map, with proper Khmer text shaping.

Everything you reach for, nothing you don't

A small, fast, native tool for people who live in SQL.

Connections

  • SSL modes from disable to verify-full, custom CA, client certs
  • SSH tunnels with password or key
  • Paste postgres:// URLs, key=value or jdbc:postgresql://
  • Copy the connection URL back out

Explorer

  • Schemas, tables, views and columns
  • Loaded on demand, so huge databases stay snappy

SQL console

  • Syntax highlighting and line numbers
  • Context-aware autocomplete: tables, columns, PostGIS functions
  • Run statement ⌘↩, run script ⇧⌘↩
  • Saved queries ⌘S, formatter ⇧⌘F, query files

Slash commands

Type in the editor, press Tab, get a complete query.

  • /con_4326, /con_4326_2 ArcGIS st_geometry via text
  • /con_merc default SRID 32648
  • /srid /top /count

Results grid

  • Virtualized, with 1,000-row server-side paging
  • Multi-row selection and pinned (frozen) columns
  • Export CSV, TSV, JSON, GeoJSON, Markdown, SQL INSERT, SVG
  • Copy as image: a PNG of the table, ready for Telegram or Slack
  • Copy for AI agent: markdown with query and column types

Inline editing

  • Double-click a cell in a table tab
  • Date/time picker for date, timestamp, timestamptz, time
  • Set NULL, pending changes highlighted
  • Save ⌘S as one transaction matched on the primary key: all or nothing

Relations

  • Right-click rows, then Related
  • Follow foreign keys both ways (→ users, ← posts) in a popup
  • Chain further, go Back, or open as a tab

PostGIS

  • Readable geometry cells
  • Built-in map: dark, light, streets, satellite
  • Client-side reprojection of WGS84, Web Mercator, UTM
  • Flags far-off (swapped lat/lon) features
  • Feature popup with copy buttons

Khmer ខ្មែរ

  • Real text shaping via HarfBuzz (rustybuzz)
  • Works in the grid, explorer, map and exported images

Polish

  • Dark, light or system theme

  • Native, small, quick to launch

A closer look

Little workflows that add up.

PostGIS

See your data on a map

Geometry columns become readable cells and one click puts them on a map. Pick a dark, light, streets or satellite basemap. rgrip reprojects WGS84, Web Mercator and UTM on the client and flags features that landed in the wrong hemisphere (hello, swapped lat/lon).

Editing

Edit cells in place

Double-click, pick a date from the calendar, set NULL. Pending changes stay highlighted until you save, and then everything goes out in a single transaction keyed on the primary key. If one row fails, nothing changes.

Relations

Follow foreign keys, both ways

Right-click a row and jump to the rows it points to, or the rows pointing at it. Keep chaining, step Back, or promote any hop to its own tab.

Grid

Pin what matters

Freeze columns so keys and names stay put while you scroll through wide tables. The grid is virtualized and pages 1,000 rows at a time from the server.

Khmer

អក្សរខ្មែរ that actually renders

Complex scripts need real shaping. rgrip uses HarfBuzz through rustybuzz, so Khmer looks right in the grid, explorer, map labels and exported images.

Sharing

Copy as image

Need to show someone a result? One click copies a PNG of the table to your clipboard, ready to paste into Telegram or Slack. There is also Copy for AI agent, which gives you markdown with the query and column types.
