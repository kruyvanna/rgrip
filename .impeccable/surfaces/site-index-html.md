# Surface: rgrip landing page (site/index.html)

Mode: Persuade. Audience: Postgres developers and PostGIS/GIS people, weighted equally. Action: Download for macOS (GitHub Releases), secondary: GitHub. Proof: real app captures (linked split-view clip, import dialog). Showcase only the must features (Map + linked grid, Import data); everything else is one short two-column list. Voice modest and plain. Lucide line icons, no emoji.

## Direction contract

THESIS: The category standard, played straight at the craft level of Zed and Linear: centered headline, the real app as the hero, two feature sections, a short list, download. Chosen by the user after the split-flap board proved hard to read.

OWN-WORLD: Near-black #0c0d10 ground, raised #14161a surfaces, hairline white-alpha borders, white primary button, the app's blue #7aa2f7 as the only accent (pill tag, feature icons). Geist and Geist Mono, self-hosted.

STORY: Visitor reads one line, sees the map and grid linked in the clip, learns import, scans the list, downloads.

FIRST VIEWPORT: Release pill, two-line headline at ~76px, one-paragraph lead, Download (white) + GitHub (ghost), a fine facts line; the split-view clip starts below, tilted back and lying flat as you scroll.

FORM: Canon (standing exit), taken after seed ba0aa259; reference products Zed and Linear. Signature interaction: the hero clip's tilt-to-flat on scroll, and a single soft rise for text as it enters; reduced motion shows everything flat and still.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
